# Avinash Singh — Software Developer & Creative Engineer Portfolio

A modern, high-performance portfolio website built with **Next.js (App Router)**, **Tailwind CSS**, and **GSAP (GreenSock)** animations.

---

## 🌟 Key Features

- **Cinematic GSAP Animations**:
  - Custom magnetic cursor follower with lerp interpolation and hover states
  - Interactive HTML5 canvas particle constellation with mouse attraction
  - Split-text reveal entrance animations and dynamic rotating roles in the Hero section
  - 3D holographic tilt on the profile card reacting to cursor angles
  - GSAP ScrollTrigger timeline with scrub progress line tracking career milestones
  - Staggered entrances on projects, skills, services, and testimonials

- **Complete Portfolio Sections**:
  1. **Navbar**: Floating glassmorphism header with active section spy, native Web Audio API sound toggle, resume launcher, and mobile drawer.
  2. **Hero Section**: Personal branding for Avinash Singh, dynamic roles, live metrics counter, CTA buttons, and social coordinates.
  3. **About Section**: Detailed technical bio, interactive 3D holographic card, core philosophy pillars, and quick stack badges.
  4. **Services Section**: 6 high-impact offerings (Full-Stack Architecture, GSAP Motion & 3D, Core Web Vitals Optimization, Startup MVPs, Design Systems, Real-Time WebSockets) with inquiry actions.
  5. **Skills Section**: Categorized arsenal (Frontend, Backend, DevOps, Tools) with animated proficiency meters and 2026 active radar.
  6. **Portfolio / Projects**: Filterable project showcase with performance metrics, GitHub links, live demo links, and deep-dive Case Study modals.
  7. **Resume & Experience Section**: Interactive career milestones timeline, education, certifications, and downloadable CV modal.
  8. **Testimonials**: Endorsements from engineering leaders and startup founders.
  9. **Contact Section**: Interactive validated contact form with celebratory confetti explosion, 1-click email copy with toast feedback, and live IST timezone clock.
  10. **Interactive CLI Terminal**: Retro-modern developer Easter egg (triggered with `[Ctrl+K]` or the terminal button) supporting commands like `help`, `about`, `skills`, `projects`, `contact`, `matrix`, and `sudo hire`.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: React 19 & TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [GSAP](https://greensock.com/) & ScrollTrigger
- **Audio**: Web Audio API (Native browser synthesizer)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: Canvas Confetti

## 🚀 Getting Started

### 1. Install Dependencies
```bash
pnpm install
# or npm install / yarn install
```

### 2. Run the Development Server
```bash
pnpm dev
# or npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### 3. Build for Production
```bash
pnpm build
pnpm start
```
